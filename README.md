
# Detector de Phishing con Python

## Descripción
Este proyecto utiliza Python para analizar URLs y detectar palabras sospechosas que pueden estar relacionadas con ataques de phishing.

## Funcionamiento
El programa identifica palabras clave como:
- login-verify
- update-account
- free-gift
- secure-bank
- confirmar-datos

## Pruebas
Se realizaron dos pruebas:
1. Una URL sospechosa que genera una alerta de phishing.
2. Una URL segura que no presenta patrones obvios de phishing.

## Lenguaje utilizado
Python 3.
